# Risk of Rain: Brawlers

Experimental, community-made **Risk of Rain-inspired arena brawler** prototype.

## Prototype scope

- Versus-first gameplay milestone
- Hybrid platform-fighter combat design
- Co-op support is a later milestone, not part of the initial prototype
- ReturnOfModding compatibility investigation before runtime hooks are implemented

## Development status

**Pre-integration scaffold.** No playable mod or verified game hooks are included yet.

## Development workflow

Integration experiments belong on a dedicated development branch. Do not publish a release, package, or distribute a playable build without explicit project-owner approval.

## Documentation

See `docs/INTEGRATION.md` for the verification checklist and `docs/PROTOTYPE.md` for the initial gameplay milestone.
